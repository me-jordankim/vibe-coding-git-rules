# 바이브코딩 Git 규칙 모음

클로드에게 붙여 넣어 쓰는 Git 작업 규칙입니다. 필요한 규칙 파일을 열고, 회색 상자 오른쪽 위의 복사 버튼을 눌러 클로드와의 새 대화에 첫 메시지로 붙여 넣으면 됩니다.

| 규칙 | 이럴 때 씁니다 |
|---|---|
| [자동 백업 규칙](auto-backup.md) | 바이브코딩을 처음 해 보고, 망쳐도 말 한마디로 되돌리고 싶을 때 |
| [작업 저장 규칙](save-and-undo.md) | 저장 지점 목록을 보면서 원하는 시점으로 골라 되돌리고 싶을 때 |
| [Git·GitHub 작업 규칙](github-sync.md) | 회사와 집처럼 여러 컴퓨터에서 같은 프로젝트를 이어서 작업할 때 |
| [브랜치·PR 작업 규칙](branch-pr.md) | 실험은 브랜치에서 하고, PR로 검토한 뒤 합치고 싶을 때 |

## 사용 방법

1. 작업할 프로젝트 폴더를 열고 클로드와 새 대화를 시작합니다.
2. 위 표에서 규칙 파일을 열고 회색 상자의 내용을 복사합니다.
3. 첫 메시지로 붙여 넣고 보냅니다.

규칙 맨 끝 문장에 따라 클로드가 규칙을 폴더의 CLAUDE.md에 저장합니다. 그래서 다음에 새 대화를 열어도 규칙이 유지됩니다.

클로드가 명령을 실행해도 되는지 묻는 창이 뜨면 허용을 눌러 주세요.
